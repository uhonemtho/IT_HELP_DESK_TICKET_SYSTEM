# Help Desk Ticket System

## Overview
A beginner-friendly browser app for recording IT issues, setting priority, resolving and reopening tickets.

## Features
Add a ticket; choose its priority; mark it resolved or reopen it; delete old tickets.

## How to run
Open `index.html` in a browser. No installation required.

## Technologies
HTML, CSS, JavaScript.
